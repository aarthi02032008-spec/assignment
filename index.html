Is 2ℤ a Subgroup of (ℤ, +)?

Using the subgroup test to show the even integers form a subgroup of the integers under addition, with a computational check of closure and inverses.

ProblemProofTry itPythonNon-examplesConclusion

01Problem Statement

Determine whether the set of even integers 2ℤ = {2k : k ∈ ℤ} = {…, −4, −2, 0, 2, 4, …} is a subgroup of (ℤ, +). Justify using the subgroup test and verify the relevant closure and inverse properties computationally.

Key ideas

  • Subgroup: a subset H of a group G that is itself a group under the same operation.
  • One-step subgroup test: H is a subgroup of G if H is non-empty and, for all a, b ∈ H, the element a − b (in additive notation) is in H.

02Justification Using the Subgroup Test

1
Non-empty. 0 = 2·0 is even, so 0 ∈ 2ℤ. Hence 2ℤ ≠ ∅, and 0 is the identity of (ℤ, +).
2
Take two elements. Let a, b ∈ 2ℤ. Then a = 2m and b = 2n for some integers m, n.
3
Apply the test. a − b = 2m − 2n = 2(m − n). Since m − n is an integer, a − b ∈ 2ℤ.
4
Conclude. By the subgroup test, 2ℤ ≤ (ℤ, +).
∎ 2ℤ is a subgroup of ℤ

Closure (derived)

For a = 2m, b = 2n: a + b = 2(m + n) ∈ 2ℤ. The sum of two even integers is even.

Inverses (derived)

For a = 2m: −a = 2(−m) ∈ 2ℤ. The negative of an even integer is even.

04Python Verification

The script checks non-emptiness, the identity, closure, inverses and the one-step subgroup test on every element of the window [−50, 50].

"""
Unit IV - Is 2Z (the even integers) a subgroup of (Z, +)?

Computational check over a finite window [-N, N] (a proof needs algebra; the
code verifies each property on every pair/element in the window, and a
counterexample test shows the checks can fail, e.g. for the odd integers).
Standard library only.
"""

N = 50  # window: integers from -N to N


def in_2Z(x):
    return x % 2 == 0


def check_subgroup(name, member, window):
    H = [x for x in window if member(x)]
    results = {}

    # Non-empty and contains identity 0
    results["non-empty"] = len(H) > 0
    results["identity 0 in H"] = member(0)

    # Closure under +  (only test pairs whose sum stays inside the window)
    closure_fail = [(a, b) for a in H for b in H
                    if abs(a + b) <= N and not member(a + b)]
    results["closure under +"] = not closure_fail

    # Inverses: -a in H for every a in H
    inverse_fail = [a for a in H if not member(-a)]
    results["inverses (-a in H)"] = not inverse_fail

    # One-step subgroup test: a - b in H for all a, b in H
    onestep_fail = [(a, b) for a in H for b in H
                    if abs(a - b) <= N and not member(a - b)]
    results["subgroup test (a - b in H)"] = not onestep_fail

    print(f"=== {name} ===")
    print(f"Elements tested in window [-{N}, {N}]: {len(H)}")
    for k, v in results.items():
        print(f"  {k:<30}: {v}")
    if closure_fail:
        print("  closure counterexample:", closure_fail[0])
    if inverse_fail:
        print("  inverse counterexample:", inverse_fail[0])
    print("  => SUBGROUP" if all(results.values()) else "  => NOT a subgroup")
    print()
    return all(results.values())


if __name__ == "__main__":
    window = range(-N, N + 1)

    # Sample demonstration
    a, b = 6, -14
    print(f"Example: a = {a}, b = {b}  ->  a - b = {a - b}, even? {in_2Z(a - b)}")
    print(f"Example: 2*k form: {a} = 2*{a // 2}, {b} = 2*{b // 2}, "
          f"a - b = 2*({a // 2} - ({b // 2})) = 2*{a // 2 - b // 2}")
    print()

    check_subgroup("2Z (even integers)", in_2Z, window)
    # Contrast: odd integers fail (no identity, not closed)
    check_subgroup("Odd integers (contrast)", lambda x: x % 2 != 0, window)
    # Contrast: 2Z union {1} style set fails closure
    check_subgroup("Evens plus the number 1 (contrast)",
                   lambda x: x % 2 == 0 or x == 1, window)

06Conclusion

2ℤ is non-empty and for any two even integers a and b, a − b is even, so by the subgroup test it is a subgroup of (ℤ, +). Closure and inverses were also confirmed computationally, while the odd integers fail the same checks.
